# 图形复制只写图形载荷

复制渲染好的图形时，剪贴板里只写 `image/png`，不同时写 `text/html` 与 `text/plain`。Word 在剪贴板同时含图片与 HTML 时优先取 HTML，粘贴结果会变成一段排版文本而不是图片，钉钉同理；所以「图形复制」必须是只写图片的独立动作，与已有的「复制代码」「复制富文本」分开。代价：粘进 markdown 编辑器拿不到图片引用，要引用时走选中复制的 HTML 出口。

## Considered Options

- **同时写图形载荷与文字载荷**：Word/钉钉的粘贴结果不可预测，可能得到排版文本而不是图片。
- **复用选中复制的多格式写入路径**：同一动作写入的格式越多，接收端选择越不可控。

## Consequences

- 图形复制是独立入口（图形容器右上角的按钮），与代码块复制按钮并列。
- 插入图片的原图字节直传，不重编码；SVG 原图才栅格化为 PNG。
- 「原图字节直传」说的是交给剪贴板的那一段：应用把原图字节原封不动交给剪贴板桥接，中间不重新编码。系统剪贴板最终以位图形式保存，像素与原图一致，字节则由系统重新编码。
