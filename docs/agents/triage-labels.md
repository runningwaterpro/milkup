# Triage Labels

技能用五个固定的 triage 角色说话。这张表把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 技能里的角色 | 本仓库的标签 | 含义 |
| ------------ | ------------ | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 agent 无人值守实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会做 |

技能提到某个角色（例如「打上 AFK-ready 标签」）时，用表里对应的标签字符串。

这五个标签在 `runningwaterpro/milkup` 里已经存在，不需要新建。

要改右列以匹配你实际在用的词表，直接编辑本文件。
